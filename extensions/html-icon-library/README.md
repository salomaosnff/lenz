# Biblioteca de ícones

Biblioteca de ícones SVG para o editor visual de HTML.

Abra pelo comando "Abrir a biblioteca de ícones" ou pela lista "Construtores de elementos" do editor
visual (item "Ícones").

## Recursos

- Mais de 2.000 ícones do [Lucide](https://lucide.dev), com busca por nome (`seta`, `arrow up`, `user`...),
  carregados só quando a janela abre
- Ajusta o tamanho, a espessura do traço e a cor; sem cor própria, o ícone herda a cor do texto ao redor
- Descrição opcional para leitores de tela; sem ela, o ícone é marcado como decorativo (`aria-hidden`)
- Insere o SVG na página (clique no ícone e em "Inserir na página", ou dê dois cliques no ícone) ou
  copia o código
- Lembra os últimos ícones usados

O SVG inserido é inline, sem arquivos externos: ele sai do tamanho pedido e usa `currentColor`, então
muda de cor junto com o texto.
