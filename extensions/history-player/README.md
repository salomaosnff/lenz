# Reprodutor de histórico

Grava as alterações feitas nos arquivos e as reproduz como um vídeo.

## Atalhos

| Atalho      | Ação                        |
| ----------- | --------------------------- |
| `Mod+Alt+R` | Iniciar ou parar a gravação |
| `Mod+Alt+H` | Abrir o reprodutor          |

## Recursos

- Reproduzir ou pausar a gravação
- Baixar a gravação e carregá-la de um arquivo
