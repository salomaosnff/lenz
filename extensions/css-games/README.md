# Jogos de CSS

Jogos para aprender CSS escrevendo CSS de verdade, do mais fácil para o mais difícil:
Fábrica de Tintas, Tiro ao Alvo, Construtor de Caixas, Cabo de Guerra, Dança das Caixas, Caça-Bugs, Pixel Perfeito e Prova de Fogo. Ficam no painel **Jogos** da barra de atividades
e abrem numa aba da área principal.

## Construtor de Caixas

Box model. O aluno acerta `padding`, `margin`, borda e `box-sizing` até a caixa ter o tamanho e a
posição do objetivo. O conteúdo é laranja e o padding é a faixa clara em volta, para ver as camadas.
11 fases, de `padding` simples até a casa completa.

## Cabo de Guerra

Especificidade. Cada fase mostra o HTML e as regras de CSS que disputam um elemento. O aluno
responde que cor vence ou ordena os seletores do mais fraco ao mais forte. Passa por classe, id,
empate, herança, atributo, pseudoclasse, estilo inline e `!important`. Ao acertar, o navegador
desenha o caso de verdade (o "tira-teima"). 14 fases.

## Dança das Caixas

Flexbox e Grid. Cada fase mostra o layout que você precisa montar: escreva as propriedades e veja
os blocos se moverem. Quando as posições batem, a fase está resolvida. 18 fases, 12 de flexbox e
6 de grid.

## Fábrica de Tintas

Cores. Passa por nomes, hexadecimal (6 e 3 dígitos), `rgb()` com transparência, `hsl()` e
contraste de texto (WCAG). Nas fases de adivinhar a cor, setas dizem, canal por canal, se precisa de
mais ou de menos, e um xadrez por trás mostra a transparência. 14 fases.

## Tiro ao Alvo

Seletores CSS. Cada fase traz um trecho de HTML e um alvo: escreva o seletor que pega exatamente
os elementos pedidos, nem a mais nem a menos. 15 fases, de `p` e `.classe` até `:not()` e
combinações.

## Caça-Bugs

Depuração. O editor começa com um CSS que tem um defeito (nome de propriedade errado, valor que o
navegador não entende, ponto e vírgula faltando, eixo trocado, linha que desfaz a outra...) e o
aluno o conserta até o quadro ficar igual ao objetivo. O editor avisa o que o navegador descartou,
como as ferramentas do navegador fazem. 10 fases.

## Pixel Perfeito

Batalha de CSS, no estilo do CSSBattle. Cada fase mostra uma imagem de 400×300 px e o aluno a
recria só com HTML e CSS (sem imagens, `url()` ou scripts). O jogo desenha o resultado e compara
pixel por pixel: com 98% de igualdade a fase está resolvida. O quadro do resultado é um comparador: passe o mouse (ou use as setas) e o objetivo aparece por cima, à direita de uma linha que segue o cursor. Há uma aba de diferenças, a lista de
cores da imagem e a contagem de caracteres, para quem quiser encurtar o código. 8 fases.

## Prova de Fogo

Quiz com as coisas mais usadas no CSS: fundamentos, seletores, cascata, box model, cores,
tipografia, flexbox, grid, posicionamento e layout responsivo. As perguntas vão do mais fácil ao
mais difícil (a ordem muda dentro de cada nível, e as respostas embaralham a cada jogada), e cada
resposta mostra a explicação na hora. No final há uma nota de 0 a 10, em que a pergunta difícil
vale mais, o desempenho por dificuldade e por assunto, e uma lista do que estudar: os assuntos em
que o aluno acertou menos de 70%, com o que revisar e um botão para praticar no jogo certo.

## Atalhos

| Atalho      | Ação                                      |
| ----------- | ----------------------------------------- |
| `Mod+Alt+G` | Abrir a Dança das Caixas (flexbox e grid) |
| `Mod+Alt+K` | Abrir o Tiro ao Alvo (seletores)          |
| `Mod+Alt+B` | Abrir o Construtor de Caixas (box model)  |
| `Mod+Alt+D` | Abrir o Caça-Bugs (CSS com defeito)       |
| `Mod+Alt+C` | Abrir o Cabo de Guerra (especificidade)   |
| `Mod+Alt+P` | Abrir a Fábrica de Tintas (cores)         |
| `Mod+Alt+A` | Abrir o Pixel Perfeito (recriar imagens)  |
| `Mod+Alt+Q` | Abrir a Prova de Fogo (quiz de CSS)       |

## Recursos

- Dica e solução em cada fase
- O progresso fica salvo no navegador; o comando "Reiniciar o progresso" zera todos os jogos
